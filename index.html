1概览：当 AI 遇上石油化工安全▼

为什么石化现场需要 AI？炼化装置区存在动火作业、高处作业、受限空间作业等高风险场景， 《中国石化安全生产行为规范》要求进入生产区必须正确佩戴安全帽等个人防护装备（PPE）。 但装置区大、人员多，纯靠安全员巡检"看不过来、盯不住"。 AI+X 的思路：用摄像头 + 目标检测模型 7×24 小时自动识别"谁没戴安全帽"，发现违章立即告警。

3目标检测基础：IoU 与置信度阈值▼

3.1 IoU：预测框和真值框重合吗？

YOLO 输出成百上千个候选框，只有和人工标注的"真值框"足够重叠（IoU ≥ 0.5）的才算有效检出。

IoU = 交集面积 / 并集面积

3.2 置信度阈值：Precision 与 Recall 的权衡

模型给每个检测框一个置信度分数（0~1）。阈值调高 → 只留"很有把握"的框：误报少（Precision 高）但容易漏检（Recall 低）；阈值调低则相反。 在石化安全场景中，漏掉一个没戴安全帽的人可能就是一起事故——所以安全应用宁可误报，也要尽量不漏检。

Precision = TP / (TP + FP)　　Recall = TP / (TP + FN)　　F1 = 2PR/(P+R)

4项目核心：安全帽佩戴判定算法 hardhat_is_on▼

检测出"人"和"帽子"只是第一步——怎么知道这顶帽子戴在这个人头上，而不是他拿在手里、掉在地上？ 本项目的答案是：在人体框的顶部中央划出一个"安全区"，只要安全帽框的中心点落在这个区域内，就判定已佩戴。

# utils/bbox_utils.py —— 项目源码（节选）
def hardhat_is_on(bbox, bbox_hh, frame):
    person_height = bbox[3] - bbox[1]        # 人体框高度
    person_width  = bbox[2] - bbox[0]        # 人体框宽度
    hardhat_height = bbox_hh[3] - bbox_hh[1]

    x1 = bbox[0] + person_width/2 - person_width/6   # 中央 1/3 的左边界
    x2 = bbox[0] + person_width/2 + person_width/6   # 右边界
    y1 = bbox[1] - hardhat_height/2                  # 顶部再往上留半个帽高
    y2 = bbox[3] - person_height*3/4                 # 底部：人体框上 1/4 处
    safe_area = (x1, y1, x2, y2)

    center = ((bbox_hh[0]+bbox_hh[2])/2, (bbox_hh[1]+bbox_hh[3])/2)
    return point_in_area(center, safe_area)

5.2 视频里的难题：检测闪断与轨迹插值

视频逐帧检测时，工人被管廊短暂遮挡，或帽子角度突变，某几帧可能"检测不到"安全帽（数值缺失）。 本项目用 Pandas 的 interpolate() 沿时间轴线性插值补齐缺失位置，再用 bfill() 处理开头缺失。

🎛️ 演示 5-2：第 4 帧安全帽检测丢失 → 插值补齐
💡 插值假设"位置随时间平滑变化"——对匀速行走的工人很有效；但如果工人突然蹲下/转身，线性插值会给出不符合真实动作的位置。跟踪（Track ID）+ 插值是视频结构化分析的通用套路。

6.3 现实局限与石化场景扩展方向

本项目局限石化场景的应对 / 扩展
只判断"帽子在不在头顶"，不判断是否系好下颚带增加细粒度分类模型或关键点检测
RGB 相机夜间失效换红外/热成像相机 + 对应数据集再训练
遮挡、密集人群易漏检多机位协同 + 跟踪轨迹融合
单一 PPE（只有安全帽）扩展类别：防静电服、护目镜、安全带、禁烟区吸烟行为
检测到违章只画框，不联动对接广播/工单系统：自动定位 Track ID → 通知区域责任人
未涉及工艺介质风险结合 DCS/气体检测数据做多模态融合（视觉 + 传感器）
⚠️ 合规提醒：现场视频涉及人员肖像与行为数据，部署时须遵循企业数据安全与个人信息保护制度， 通常做法是边缘端推理、只输出"违章事件"而非存储原始视频。
